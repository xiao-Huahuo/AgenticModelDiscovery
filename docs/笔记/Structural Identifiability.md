| **A15**  | **GFN-SR: Symbolic Regression with Generative Flow Networks**（Li, Marinescu & Musslick, 2023）                                                   | **任务：**DSR 等深度 SR 直接最大化 reward，训练后往往集中在一个高分模式；噪声下“错误但高 reward”的邻近结构会吸走搜索，降低正确公式恢复率。                                | 用 **Generative Flow Network, GFlowNet** 学习与 reward 成比例的表达式生成分布，使模型天然采样多样化的高质量候选；再通过 reward baseline 兼顾探索和高分区域利用。                                                                             | 无噪 Nguyen benchmark 上与 DSR、GP、BSR 竞争；更关键的是 10% 噪声的“近似可混淆公式对”实验。GFN-SR 六个方程恢复率分别为 **100%、15%、15%、95%、95%、85%**，多数高于 DSR 与 BSR，说明多模态生成在结构歧义下更容易保住真式。                                                                                                                 | 它采用 reward-proportional 的生成分布，非常适合做 **LLM-SR 的多样化 proposal 对照**；严格 Bayesian posterior 可由独立证据层负责。当前经验池虽有 multi-island，但最终仍按分数集中。可以比较“LLM 多岛采样”与 GFlowNet 式按 reward 分布采样，看结构多样性究竟来自语言先验还是采样目标。                 |                                                                                                                                                  |

## B. 数学等价类与结构去重

|编号|论文|任务与痛点|解决方案|实验与主要结论|与当前 LLM-SR 方向的联系|

|**B01**|**EGG-SR: Embedding Symbolic Equivalence into Symbolic Regression via Equality Graph**（Jiang, Wang & Xue, 2025）|**任务：**SR 搜索空间里存在大量数学上等价、语法上不同的表达式。搜索器会反复访问同一语义类，posterior 也会被同一关系的多个写法重复分票。|把 **e-graph / equality saturation** 嵌入 MCTS、DRL 和 LLM-SR。等价变换规则把大量表达式压缩到同一个 equality graph 中，搜索器可以利用整个等价类做扩展、反馈和梯度估计。|Egg-MCTS、Egg-DRL 在包含大量三角恒等变换的任务上优于原算法，e-graph 对指数级等价式的存储显著更省内存，额外时间开销相对常数拟合和神经更新很小。**最关键的是它直接改造了 LLM-SR**：GPT-3.5 在 bacterial growth 的 OOD NMSE 从 0.0264 降到 **0.0198**，stress-strain 从 0.0516 降到 **0.0419**；Mistral 的 Oscillation II OOD 从 0.0291 降到 **0.0114**。|**必读，而且已经直接撞到 LLM-SR。** 当前“结构 posterior”若按程序字符串计数，会把 `x+x` 与 `2x` 等等价式当成两个模型。B01 给出可落地的 equivalence layer。下一步更合理的是在 e-class 上聚合 posterior，再把真正行为不同的 e-class 交给主动证伪。|
|**B02**|**Improving Genetic Programming for Symbolic Regression with Equality Graphs**（de França & Kronberger, GECCO 2025）|**任务：**传统 GP 的交叉和变异常生成已经访问过、或仅做代数改写的表达式，预算大量消耗在语义重复上；表达式简化通常又只发生在搜索后端。|维护贯穿搜索过程的 e-graph，记录已访问表达式及其数学等价形式；在 crossover / mutation 时查询 e-graph，优先生成尚未访问的新语义结构，并利用 equality saturation 自动简化冗余参数和表达式。|在 12 个 SRBench 与 9 个真实数据集上同 tinyGP、Operon、PySR 比较。eggp 的多目标版本在 SRBench 测试 R² 中平均排名约 **2.50**，与 Operon 接近，并通常返回更小表达式；真实数据上总体接近最佳基线。代价是当前实现约为 Operon 的 **5 到 15 倍**运行时间。|它解决的是 **搜索历史去重和语义新颖性**，恰好对应 LLM-SR experience buffer 的缺口。当前经验池按 score/cluster 管理，但不同程序可能只是同一数学关系的变体。加入 e-graph 后，经验池可以按 e-class 存储，真正的“多样性”变成结构语义多样性。|

## C. 主动区分结构与最优实验设计

|编号|论文|任务与痛点|解决方案|实验与主要结论|与当前 LLM-SR 方向的联系|
|---|---|---|---|---|---|
|**C01**|**Active Learning in Genetic Programming: Guiding Efficient Data Collection for Symbolic Regression**（Haut, Banzhaf & Punch, 2025）|**任务：**当实验数据昂贵时，SR 需要决定“下一条数据采在哪里”而非被动等待更多样本。随机采样容易把预算浪费在候选模型意见一致的区域。|直接利用 GP 种群形成模型 ensemble，以预测分布计算 uncertainty；比较多种指标后选出 **differential entropy**，同时研究最小欧氏距离和相关性等样本多样性指标，并用 Pareto 优化尝试联合 uncertainty 与 diversity。|在 35 个主要 Feynman 问题及额外 SRBench 任务上做大量重复实验。differential entropy 整体表现最好；在 35 个问题中，相比 uniform random sampling，相关性多样性策略有 **29/33** 个问题持平或更优，最小距离为 **27/35**。论文结论是 GP ensemble 的不确定性能够有效降低达到正确结构所需的数据量。|这正好接在结构 posterior 后面。LLM-SR 已有多个高分候选时，可以在可控输入或故障空间搜索 **候选分歧最大的 x / 扰动**，然后补一条真实观测再更新 posterior。它把“identifiability 是问题”推进成了“下一步该采什么数据”。|
|**C02**|**Active Learning Improves Performance on Symbolic Regression Tasks in StackGP**（Haut, Banzhaf & Punch, GECCO 2022）|**任务：**用尽量少的数据恢复科学公式。固定训练集下，很多点对区分候选结构贡献很小，而复杂实验或标注具有实际成本。|从很小的初始数据集启动 StackGP，用当前 GP 模型 ensemble 的预测不确定性在候选输入中选择下一点，加入数据后重新运行 SR，循环直到达到终止条件。|在 100 个 Feynman 方程上测试，方法最终成功恢复 **72/100**，且很多公式只需很少数据点；整个过程不依赖量纲分析、数据变换或人工领域技巧。作者也发现某些分母型问题会误导不确定性指标，说明 active acquisition 自身也需要更好的多样性约束。|它是最直接的“**SR 搜索 ↔ 数据采集闭环**”原型。替换 StackGP 为 LLM-SR 后即可得到基础版本，但当前研究还可再加一层：采样目标不要只最大化预测 variance，而要直接最大化**不同结构 posterior 之间的可判别性**。|
|**C03**|**Ensemble-SINDy: Robust sparse model discovery in the low-data, high-noise limit, with active learning and control**（Fasel et al., Proc. Royal Society A, 2022）|**任务：**SINDy 在低数据、高噪声下容易错选方程项，也缺乏对“哪些项真正属于模型”的置信度；固定数据采样进一步限制结构恢复。|用 bagging / library bagging 构造 **E-SINDy**，从 ensemble 统计量得到系数分布和 term inclusion probability；再以 ensemble forecast variance 选择新的初始条件进行主动采样，并把同一不确定性用于控制。|在 ODE/PDE benchmark 上，ensemble 明显提升低数据和高噪声下的结构恢复；E-WSINDy 将可容忍噪声水平提高约 **2.3 倍**。Lorenz 主动学习中，高 forecast variance 的初始条件被优先采样，系数方差下降且正确结构所需数据减少；控制实验中 E-SINDy 也在短数据条件下优于标准 SINDy。|这是当前方向非常完整的 **“结构 UQ → 主动采样 → 后验收缩”**参考，只是结构空间固定在 SINDy dictionary。LLM-SR 可以把 free-form 候选接到相同闭环，进一步用电力故障/扰动作为主动实验变量。|
|**C04**|**Optimal experiment design for practical parameter identifiability and model discrimination**（Liu, Maini & Baker, 2025）|**任务：**已有多个动力学模型都能拟合当前数据时，需要设计外部控制输入，让模型在新实验中产生尽量不同的预测；这与改善单个模型的参数可辨识性是两个不同目标。|参数可辨识性部分用 profile likelihood 衡量；**模型区分**部分写成 optimal control problem，目标函数直接扩大 rival models 的轨迹差异，并用 Pontryagin Maximum Principle 与 forward-backward sweep 求最优控制。|在 logistic / Richards 等 ODE 模型及信号通路案例中展示。论文明确发现，用于提高 parameter identifiability 的最佳控制与用于 model discrimination 的最佳控制可以不同；通过优化输入，可明显拉开原先接近的模型轨迹，并使后续数据更有判别力。|与当前设想的 **active falsification** 最直接。LLM-SR 先产生若干结构类并拟合各自 θ，然后把这些模型的响应差异写进控制目标，在电力系统允许的扰动空间寻找最能区分候选的事件，而非盲目再采正常运行数据。|
|**C05**|**Optimal Experimental Design for Model Discrimination**（Myung & Pitt, Psychological Review, 2009）|**任务：**多个理论模型对现有实验都解释良好时，实验设计本身决定了能否区分模型。常规实验常凭经验选择刺激或采样时刻，信息量并未最大化。|把设计优化转成 Bayesian simulation problem，用 MCMC 与 simulated annealing 搜索使 **model recovery probability** 最大的实验设计；方法同时考虑模型和参数的不确定性，并支持连续或离散设计变量。|遗忘模型实验中，3 个采样时刻的最优设计 recovery **86.3%**，线性/几何设计仅 58.3%/61.9%；5 点最优设计达 **91.5%**，达到 90% recovery 所需试验数仅约普通方案的 1/6 到 1/9。分类模型中最优设计 recovery **96.3%**，简单设计约 53.1%。论文还指出，即使最优设计仍无法区分时，模型在该实验条件下具有实质性不可区分性。|它给“主动证伪”提供了非常清晰的目标：**优化的是模型恢复/区分概率，而非单纯预测方差。** 当前 LLM-SR 可以把每个结构 posterior mode 当 rival model，设计下一次故障或激励，并在新数据回来后循环更新 posterior。|
|**C06**|**An anticipatory approach to optimal experimental design for model discrimination**（Donckels et al., Chemometrics, 2009）|**任务：**rival dynamic models 的均值预测即使差异很大，若测量误差或参数传播造成的 prediction uncertainty 同样很大，实验仍缺乏判别力。|在经典 OED/MD 目标中同时加入 measurement uncertainty 与 model prediction uncertainty，并提出 **anticipatory design**：在实验真正执行前，预估新数据会如何收缩参数不确定性，再据此选择采样时刻。|以两个竞争的酶动力学模型为案例，优化给定输入轨迹下的采样时间。anticipatory 方法会把样本放在“模型预测差异大，同时预测区间可被新样本有效收窄”的位置，从而提高区分能力；文中显示有些位置单采一个点仍不足，增加采样后才值得利用该分歧区域。|对电力动态模型尤其合适。候选结构的参数也有不确定性，直接看两条 MAP 轨迹差异会高估可判别性。更稳妥的目标是比较 **posterior predictive distributions**，同时考虑测量噪声和 θ 后验，再选择能真正分离结构的扰动。|

|**E01**|**Comprehensive Framework for Model Discovery and Discrimination Based on Symbolic Regression and Structural Identifiability**（Yuan & Benyahia, ESCAPE 2026）|**任务：**部分状态不可观测时，SR 即使拟合很好，候选模型也可能在参数上不可唯一辨识，或隐藏状态不可观测，导致后续预测和控制失去可靠基础。|用 PySR 生成候选动力学模型，以 AIC 做初筛，再调用 **STRIKE-GOLDD** 检查 structural identifiability and observability, SIO；若发现缺陷，用 AutoRepar 重参数化并继续搜索，形成 SR 与 SIO 联合循环。|在部分观测的 sulfide oxidation 系统上演示，从有限测量与少量先验中得到拟合良好且通过 SIO 检查的模型。作者强调，纯数据拟合会留下 non-identifiable 或 structurally inconsistent 候选，而 SIO 可大幅缩小可接受模型集。|**用于划清术语边界。** 这里的 structural identifiability 主要问“给定 G 后，θ 和 hidden state 能否唯一恢复”，与当前“多个不同 G 都能解释 D”属于两层问题。未来 LLM-SR verifier 可以同时做两关：先检查每个 G 自身的 SIO，再在通过者之间处理结构 posterior 与主动区分。|
|**E02**|**PyCC.id: A package for hypothesis-driven equation discovery with structural identifiability**（Gonzalez, 2026）|**任务：**数据驱动方程发现经常产生大量拟合相近的候选，研究者只能事后凭领域知识筛选；另一方面，完全自由搜索又容易违反已知机理。|用 **hypothesis skeleton** 先定义 ODE 家族和已知结构，再让 NN、symbolic regression 或 polynomial 方法学习 skeleton 中未知的 constitutive functions；某些 skeleton 具有可证明的 structural identifiability，可据此接受或淘汰假设。|软件论文用含黏性、Coulomb friction、线性与三次恢复力的二阶受迫振子展示完整工作流。用户可约束函数奇偶性、零点等先验，再学习未知 `f1(v)`、`f2(x)`；重点是可复用工具链和 hypothesis-driven workflow，而非大规模 benchmark。|它代表 **“自由发现”与“机理 skeleton”之间的中间路线**。当前 LLM-SR 可以让 LLM 生成 skeleton，再由 PyCC.id 式 formal identifiability 检查某个 skeleton 是否在理论上可辨识。它仍解决给定假设族内部的可辨识性，不等同于结构 posterior。|

## 与当前 LLM-SR 方向的整体对应

这批文献把当前问题切得很清楚。A02、A03、A04、A05 已经把“从一个最佳公式升级到多个公式及其 posterior”做成了正式方法，因此只做 `LLM-SR + p(G|D)` 研究重叠很高。B01 更进一步，已经把 equality graph 直接接进 LLM-SR，并在原论文的四个科学 benchmark 上得到改进。

当前资料中仍然更稀缺的是一条完整链：**LLM 负责 free-form、science-aware structure proposal；等价结构先聚成 e-class；posterior 在 e-class 层维护真正有差异的竞争结构；系统再主动设计故障、激励或采样位置，使这些结构的 posterior predictive response 最大程度分离；新数据回来后执行 falsification 与 posterior update。** C01 到 C06 给出了主动采样和 model discrimination 的成熟部件，D 组给出 fixed-dictionary 的结构 UQ baseline，E 组负责检查每个候选结构自身的参数/状态可辨识性。

因此，针对当前 LLM-SR 的“identifiability”痛点，最关键的区分是两层：`G` 之间的结构不确定性由 A、B、C 组处理；给定 `G` 后 `θ` 是否唯一以及隐藏状态是否可恢复，由 E 组处理。两层都通过后，再谈最终可信方程。
