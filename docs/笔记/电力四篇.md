| **《交互式多模型电力负荷建模问题研究》**             | 面向负荷时变特性，实现在线负荷模型选择、参数估计与多模型融合                 | 实际负荷构成随时间、季节、运行状态变化，单一固定模型难以长期保持较高精度；不同节点之间还存在网络耦合     | 构建多个候选负荷模型，通过 **IIMM 交互式多模型机制 + EKF** 并行辨识，根据实时预测误差动态更新模型概率并融合输出；同时利用 **GCN** 处理节点耦合，并对季节负荷模式进行分类 | **联系最直接。** 可以视为早期的 `Router + Model Pool`。当前方向可以进一步把人工预设模型池扩展为 **LLM 自动生成候选模型 + Router 动态选择 + Verifier 筛选**，从“选已有模型”推进到“自动发现新模型” |

| **《电力系统负荷建模研究综述与展望》**              | 总结负荷建模的发展路线、模型类型、辨识方法和未来趋势                     | 传统负荷模型逐渐难以覆盖新能源、电力电子设备和复杂新型负荷；研究通常把模型结构与参数辨识分开处理       | 总结静态模型、动态模型、综合负荷模型和参数辨识方法，并提出向 **广义综合负荷、在线建模、分类分时模型库、人工智能辅助建模** 演进                                | 给当前方向提供理论定位。传统方法主要解决 `给定 f(x;θ)，求 θ`，而 LLM-SR 进一步解决 **连 f 的结构一起搜索**。它可以作为论文 Introduction 中说明“从参数辨识走向结构自动发现”的核心文献                |
| **《面向智能电网的广义综合负荷建模方法研究》**          | 在智能电网环境下，根据季节、时段和负荷组成变化动态建立综合负荷模型，并把分布式新能源纳入模型 | 行业负荷比例持续变化，传统固定负荷构成容易失真；分布式风电、储能等新设备加入后，原有负荷模型结构覆盖范围不足 | 利用 **SCADA 日负荷曲线、聚类、模式识别、模糊综合评价** 在线估计工业、商业、居民等组成比例，并进行分时修正；进一步建立包含传统负荷、感应电机、无功补偿和分布式风电的广义综合模型    | 说明了为什么需要 **动态模型库和结构演化机制**。当前方向可以由 Agent 根据负荷组成变化决定沿用已有模型、调整参数，或调用 LLM-SR 搜索新结构，从而形成持续扩充的负荷模型库                                   |
