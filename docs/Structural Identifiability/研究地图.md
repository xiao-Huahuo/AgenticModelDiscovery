# 结构不确定性研究地图

| 层 | 代表论文 | 已解决的问题 | 对 LLM-SR 的含义 |
|---|---|---|---|
| 单一最优公式 | 传统 SR / LLM-SR | 搜索一个高分表达式 | 无法表达“多个结构同样可信” |
| 结构 posterior | ERRLESS、Posterior Sampling、HierBOSSS、VaSST | `p(G|D)`、多个 plausible structures | 这一层已有强前人工作 |
| 结构等价类 | EGG-SR、EGGP | 归并数学等价的不同语法表达式 | posterior 更应建立在 semantic equivalence class 上 |
| 主动采样 | Active Learning GP、E-SINDy | 去高 disagreement 区域采新数据 | 已能用候选模型分歧指导数据采集 |
| 主动模型区分 | OED for Model Discrimination | 设计让 rival models 预测分离最大的实验 | 很适合升级成 falsification-first SR |
| 动态场景闭环 | 尚需继续核新颖性 | posterior → 等价归并 → 主动扰动 → 证伪 → 更新 | 这是比“单纯结构 posterior”更有潜力的方向 |

## 最关键的边界

“structural identifiability”在控制、化工和系统生物学里经常指：**给定一个模型结构以后，参数是否能由理想输入输出唯一恢复**。  
你当前关心的是另一件事：**多个不同模型结构在有限观测域上都成立时，结构本身如何表示不确定性、如何设计新实验把它们区分开**。

E01-E03 用来建立这个术语边界，避免后续检索被大量参数 identifiability 文献淹没。
